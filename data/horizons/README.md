# Еталонні дані JPL Horizons

Оракул, відносно якого вимірюється власне ядро (ROADMAP B1). Дані статичні;
вивантажені один раз скриптом [`scripts/fetch_horizons.sh`](../../scripts/fetch_horizons.sh)
і закомічені навмисно — щоб тести не залежали від мережі й від того, чи
змінився API.

> Скрипт перезаписує лише `vec_*.csv`, `obj_*.txt` і `gm.csv`. Цей README він
> не чіпає — але `rm -rf data/horizons` перед перевивантаженням знесе і його.

## Параметри запиту (частина контракту даних)

| Параметр | Значення | Чому саме так |
|---|---|---|
| `CENTER` | `500@0` — барицентр Сонячної системи | PROJECT.md §4: барицентрична інерціальна |
| `REF_PLANE` + `REF_SYSTEM` | `FRAME` + `ICRF` | Екваторіальна ICRF, **не екліптика** |
| `OUT_UNITS` | `KM-S` | У метри конвертує завантажувач |
| `VEC_CORR` | `NONE` | Геометричні вектори, без світлової затримки й аберації |
| Час | JDTDB | Барицентричний динамічний, без високосних секунд |
| Інтервал | 2000-01-01 12:00 .. 2010-01-01 12:00 | 10 років для регресії B5 |
| Крок | 30 діб | 122 точки на тіло |
| Джерело | DE441 | Повідомляє сам Horizons |

Зміна будь-чого з цього робить дані несумісними з попередніми. Більшість
розбіжностей у чисельних задачах народжується саме тут, а не у фізиці.

## Файли

- `vec_<тіло>.csv` — `jdtdb,x_km,y_km,z_km,vx_kms,vy_kms,vz_kms`
- `obj_<тіло>.txt` — сира сторінка параметрів тіла з Horizons (походження GM)
- `gm.csv` — `name,gm_km3_s2`, витягнуто з `obj_*.txt`

## Склад: усі великі тіла Сонячної системи

`sun`, `mercury`, `venus`, `earth`, `moon`, `mars_bary`, `jupiter_bary`,
`saturn_bary`, `uranus_bary`, `neptune_bary`.

Спокуса обмежитись Сонцем, Землею й Місяцем існує, але B5 виміряв її ціну:
підсистема з кількох тіл несе лише частину імпульсу Сонячної системи, тож її
спільний барицентр лінійно дрейфує крізь систему SSB — **4.96·10⁹ м за 10 років
для трьох тіл проти 1.05·10⁶ м для повного набору**. Цей дрейф запікся б
в ассет ефемериди назавжди.

## Відкрите питання: GM барицентрів

Вектори барицентрів (`COMMAND` = 4, 5, 6, 7, 8) описують динамічні точки,
власного GM для яких Horizons не публікує, тож у `gm.csv` для них лежить GM
**планети** зі сторінок 499, 599, 699, 799, 899.

Для Марса різниця нехтовна. Для газових гігантів супутники дають порядку
0.01–0.02% — помітно, якщо колись знадобиться точність краща за цю величину.
На поточному рівні (похибка Землі 1.7·10⁶ м за 10 років) це не домінує.

**Не вигадувати число.** Коли знадобиться — взяти системний GM з окремого
джерела (наприклад заголовка ядра DE441) або підсумувати GM планети
й супутників з Horizons.

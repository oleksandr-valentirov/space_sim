# GRAIL: місячне гравітаційне поле (ROADMAP K5e)

`grgm900c_d50_sha.tab` — **дослівний початок** таблиці GRGM900C, обрізаний по
ступеню 50. Нічого не переформатовано й не переобчислено: рядки саме такі, як
у джерелі, щоб файл можна було звірити з ним `diff`-ом.

## Джерело

- Модель: **GRGM900C**, GSFC, степінь і порядок 900.
- Файл: `gggrx_0900c_sha.tab`, PDS Geosciences Node,
  `https://pds-geosciences.wustl.edu/grail/grail-l-lgrs-5-rdr-v1/grail_1001/shadr/`
- Опис формату: `gggrx_0900c_sha.lbl` там же (PDS3, `RECORD_BYTES = 122`).
- Завантажено: 2026-08-15.

Цитувати належить **Lemoine et al. (2014)**, GRL,
[doi:10.1002/2014GL060027](https://doi.org/10.1002/2014GL060027). Дані NASA —
суспільне надбання; вимога цитування наукова, не ліцензійна, і виконується
тут та в `core/cook/cook_fixture.c`.

## Як відтворити обрізання

```sh
curl -r 0-204799 -o head.tab \
  https://pds-geosciences.wustl.edu/grail/grail-l-lgrs-5-rdr-v1/grail_1001/shadr/gggrx_0900c_sha.tab
# рядки фіксовані по 122 байти, тож перших 200 КБ вистачає до ступеня ~57;
# лишити заголовок і всі рядки з n <= 50.
```

Межа 50 — не смак: це `HARMONICS_MAX_DEGREE` (`core/harmonics.h`), і вибрана
вона тим, що ненормована рекурсія розсипалась близько 44 (ROADMAP K5b).
Потрібен інший ступінь — перекачати з іншою межею й підняти константу; формат
файлу від цього не змінюється.

## Що всередині

Перший рядок — заголовок:

```
опорний радіус (км), GM (км³/с²), σ(GM), степінь, порядок, нормування, λ₀, φ₀
 0.1738000000000000E+04, 0.4902799967088640E+04, ..., 900, 900, 1, 0.0, 0.0
```

Далі по рядку на пару: `n, m, C_nm, S_nm, σ(C), σ(S)`.

Три властивості, від яких залежить решта коду:

1. **Коефіцієнти повністю нормовані** (поле «нормування» = 1) — рівно та сама
   форма, у якій їх тримає `HarmonicsField` з K5b. Перетворення не потрібне,
   і це не збіг: нормованими їх публікують саме тому, чому K5b перейшов на
   них — ненормовані переповнюють `double` десь із 44 ступеня.
2. **Опорний радіус 1738.0 км** — не середній радіус Місяця з ассета
   (1737.53 км). Це різні числа з різним призначенням: одне нормує ряд, друге
   малює тінь і міряє висоти. Плутати їх — класична помилка.
3. **Система — головні осі (PA)** за DE421, не середня IAU, яку дає
   `core/offline/body_rotation.c`. K5c виміряв, що це коштує: кутова хвилина
   розбіжності кадру — 0.1% масконного сигналу, тобто **поправка не
   потрібна**. Не «забули», а перевірено й визнано неістотним.

σ-стовпці ніхто не читає. Вони лишені навмисно: файл має лишатися дослівним
уривком джерела, а не нашою вибіркою з нього.
